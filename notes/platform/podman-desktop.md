# Podman Desktop

**Layer:** Platform (GUI)  
**Index:** [platform.md](../platform.md)

## Role

**Podman Desktop** is an optional **graphical app** (Windows, macOS, Linux) for:

- Images, containers, pods, volumes
- **Podman Machine** settings (Mac/Win)
- Logs, terminal, port forwarding UI
- Extensions (Kubernetes context, etc.—varies by version)

Same engine as CLI; Desktop is a **client**, not a replacement for `dockerd`.

## vs CLI

| Use Desktop | Use CLI |
|-------------|---------|
| Visual browse, beginner-friendly | Scripts, SSH, automation |
| Machine resource sliders | `podman machine init` flags |
| Quick log tail | `podman logs -f` |
